## EN

**WOOQ** is a fast, lightweight, and modern desktop application that captures on-screen text in real time from games, videos, or any window and translates it instantly into any language you choose.

### How It Works

| 1. Select Area | 2. Real-Time OCR | 3. Instant Overlay |
| :---: | :---: | :---: |
| Pick the subtitle region on your screen. | Local OCR engine reads text with low latency. | Translated text appears cleanly on top in your chosen language. |

### Key Features

| Feature | Description |
| :--- | :--- |
| **Multi-Language Support** | Switch source and target languages anytime directly inside the app. |
| **Fast Local OCR** | Detects on-screen text with minimal CPU usage and low latency. |
| **Game & Video Ready** | Works seamlessly over Borderless Windowed games and media players. |
| **Modern Dark UI** | Clean, distraction-free overlay and interface design. |
| **Auto-Updater** | Automatically checks for and installs new releases in the background. |

### Installation

1. Click the green **DOWNLOAD** button above to get `WOOQ_Setup.exe`.
2. Run the installer and finish setup in seconds.
3. Launch **WOOQ** from your desktop shortcut, choose your language, and select the subtitle area.

### Hotkeys

| Shortcut | Action |
| :---: | :--- |
| `Alt + W` | Toggle main menu |
| `Alt + X` | Pause / Resume translation |
| `Alt + C` | Copy latest translation to clipboard |

### FAQ

<details>
<summary><b>Windows SmartScreen says "Windows protected your PC"</b></summary>
<br>
Because WOOQ is an indie release without a paid code-signing certificate, Windows may show a warning on first launch. Click <b>More info</b> → <b>Run anyway</b> to proceed.
</details>

<details>
<summary><b>Overlay is not visible in-game</b></summary>
<br>
Switch your game's display mode from Exclusive Fullscreen to <b>Borderless Windowed</b>.
</details>
